# Публікації та завантаження головного банера

Новини `/news`, блог `/blog` і благодійність `/about/charity` отримують опубліковані записи з `admin/content`. Вони показуються в основній сітці сторінки, без секції «З адмінки». Завантаження списків відбувається на сервері; чернетки та записи тексту сторінок не потрапляють у сітку. За відсутності матеріалів показується порожній стан, за помилки БД — повідомлення про тимчасову недоступність.

Демонстраційні масиви `content/blog.ts`, `content/news.ts`, `content/charity.ts` очищені. Сумісні експорти залишено для наявних споживачів (меню, категорії, детальні маршрути). Збережені в БД матеріали не видаляються. Для появи матеріалу виберіть тип Новини / Блог / Благодійність, призначення «Окрема стаття» та статус «Опубліковано».

На сторінках співпраці прибрано службові заглушки з шляхами до відсутніх txt-файлів. Статичний текст показується лише за наявності. Текст через admin/content та візуальний редактор продовжує працювати.

Карусель використовує Next Image замість повнорозмірних img: адаптивні розміри, quality 75, пріоритетне завантаження першого зображення. Проксі зображень підтримує закодовані пробіли й кирилицю. Завантаження банерів та статистики магазинів на головній виконується паралельно. Налаштування відео не змінено; для великих відеофайлів потрібна оптимізована вебверсія (див. banner-video.md).

Перевірки: `node scripts/check-public-publications.cjs`, `node scripts/check-banner-playback.cjs`, TypeScript та повна production-збірка. Час завантаження на віддаленому сервері не вимірювався; зміни не розгорнуті.
