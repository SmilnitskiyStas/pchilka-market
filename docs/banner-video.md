# Відео у банерах

Наданий `img/video-baner/1 тиждень АЛК.mp4` має тривалість 46 секунд, H.264, 1696×1080, 25 кадрів/с, приблизно 14,65 Мбіт/с та розмір 84 261 322 байти.

Вебверсія: `public/img/banners/week-1-alk-web.mp4`, публічна адреса `/img/banners/week-1-alk-web.mp4`. Параметри: H.264, 1280×816 зі збереженням пропорцій, 25 кадрів/с, без аудіодоріжки, CRF 24, preset slow, maxrate 2400k, bufsize 4800k, yuv420p, `-movflags +faststart`. Тривалість 46 секунд, розмір 4 467 269 байтів, середній бітрейт близько 0,78 Мбіт/с. Оригінал збережений без змін. FFmpeg/FFprobe для підготовки встановлювалися лише в `tmp/video-tools`; для відтворення на сервері вони не потрібні.

Після розгортання виберіть вебверсію в Admin → Маркетинг → Банери → Медіафайли, або задайте її публічну адресу як джерело наявного банера. Старий завантажений 84-МБ файл автоматично не перезаписується, а налаштування банера у віддаленій БД не змінювалися.

Карусель монтує лише активне відео, щоб приховані ролики не завантажувалися одночасно. Відеослайд показується до завершення ролика, після чого відкривається наступний слайд; один відеослайд повторюється. Для зображень зберігається таймер перемикання. Відео й таймер зупиняються, коли банер поза екраном або вкладка прихована. При помилці відео в каруселі з кількома слайдами таймер дозволяє перейти далі.

Маршрут `/media/*` коректно підтримує кінцеві діапазони `Range: bytes=-N` та HEAD-запити без читання тіла файлу. `moov` у вебверсії розташований перед `mdat`, тому браузер може почати відтворення, не завантажуючи весь файл.

Перевірки: `npm run typecheck`, `node scripts/check-banner-playback.cjs`. Сценарій перевіряє завантаження лише активного відео, перемикання після завершення, паузу у фоні, цикл одного ролика, діапазони байтів, HEAD і розташування метаданих MP4.
