# Сторінки каталогів Ф1 і Ф3

Керування: Admin → Маркетинг → Акції → Каталог.

- Початкові сторінки: `/promotions/catalog/f1` і `/promotions/catalog/f3`.
- `/promotions/catalog` показує список видимих сторінок. Наявні PDF без призначення відносяться до Ф1; старе налаштування архіву зберігається для Ф1.
- У блоці «Сторінки каталогів» можна створювати, редагувати та видаляти сторінки, задавати назву, частину URL і призначення. URL має містити латинські літери, цифри й дефіси, бути унікальним.
- Прапорець «Показувати у списку каталогів і карті сайту» керує публічним переліком. Прихована сторінка доступна за прямим посиланням, не входить до sitemap та отримує `noindex,nofollow`. Це приховування навігації, а не обмеження доступу до PDF.
- Перед завантаженням PDF обирається сторінка. На кожній сторінці актуальним стає її найновіший каталог; архів вмикається окремо.
- Кнопка «Редагувати / перенести» дозволяє призначити вже завантажений PDF іншій сторінці без повторного завантаження.
- Сторінку з прив'язаними PDF видалити не можна: спочатку перенесіть або видаліть каталоги. Видалення порожньої сторінки прибирає її посилання з публічного списку; її URL повертає 404.

Дані зберігаються поряд з наявними каталогами в `UPLOADS_DIR/promotions/catalogs/catalog-pages.json`. Призначення PDF записується в `catalog-metadata.json` через поле `pageId`. Під час перенесення сервера потрібно переносити весь `UPLOADS_DIR`, як і раніше; зміни схеми БД не потрібні.

Перевірки: `npm run typecheck` та `node scripts/check-promotion-catalog-pages.cjs`. Інтеграційна перевірка створює ізольовану тимчасову папку та не змінює робочі каталоги.
