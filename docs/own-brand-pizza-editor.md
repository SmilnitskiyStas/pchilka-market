# Редактор піци та магазинів

Сторінка адміністратора: `/admin/own-brand`. Публічна сторінка: `/own-brand/pizza-coffeehouse`.

## Піци

Збережені картки спочатку згорнуті. У заголовку видно назву, вагу й позначку неактивної позиції. Натискання на назву відкриває поля редагування; нова піца відкривається відразу. «Згорнути всі піци» закриває відкриті картки, зберігаючи незбережені зміни в поточній вкладці. Якщо при збереженні бракує назви, відповідні картки відкриваються для виправлення.

## Магазини з піцою

Блок над списком піц показує активні магазини з довідника, у яких заповнено місто й адресу. Можна шукати за назвою, кодом, містом або адресою, позначати окремі магазини та вибирати всі знайдені. Пошук не скидає раніше обрані магазини.

«Зберегти магазини» публікує тільки вибір магазинів і не зберігає незавершені правки піц. Після збереження адреси на публічній сторінці беруться з актуального довідника та групуються за містом. Неактивні чи видалені магазини не показуються. Щоб додати відсутній магазин або заповнити адресу, спочатку відредагувати довідник магазинів.

Порожній збережений вибір означає відсутність адрес на сторінці. До першого збереження підтримується попередній текстовий список, якщо такий файл існує. У редакторі автоматично позначаються тільки точні збіги міста й адреси; для незіставлених адрес показується попередження перед заміною списку.

## Зберігання та API

- Піци: `/app/content/own-brand-pizzas.json`; production bind mount `/srv/pchilka-app/data/app/content:/app/content`.
- Вибір магазинів: `UPLOADS_DIR/own-brand/pizza-stores.json`, тільки `storeIds`, атомарний запис. Папка uploads уже постійна та резервується разом з рештою медіа.
- Адреси та стан магазинів: поточна таблиця `stores`, без зміни її схеми чи даних.
- API: `GET/PUT /api/admin/own-brand/pizza-stores`; права `own_brand:read` і `own_brand:write` відповідно. Некоректні, невідомі та неактивні ID відхиляються до запису.
- Попередні файли `pizza_store.txt` і `pizza_list.txt` є лише джерелами сумісності до появи збережених налаштувань/піци.

Перевірка: `node scripts/check-own-brand-editor.cjs`. Вона використовує тимчасові файли та підмінений довідник, перевіряє права, публічний вибір, порожній список, згорнуті картки, збереження правок і пошук без записів у робочу БД.
