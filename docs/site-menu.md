# Редактор меню сайту

Admin → Контент → Меню сайту (`/admin/menu`). Початкова структура повторює чинні шість головних розділів і їхні підменю.

Редактор дозволяє створювати, перейменовувати, видаляти й переставляти пункти стрілками або перетягуванням. Поле «Де розмістити» переносить пункт у головний рядок чи підменю іншого розділу. Пункт із власним підменю залишається на першому рівні; підтримуються два рівні. Видалення розділу видаляє також його підменю після збереження. До збереження «Скасувати зміни» повертає останню збережену структуру.

Можна обрати готову сторінку, каталог Ф1/Ф3 або вказати внутрішню адресу чи HTTPS-посилання. `#` означає групу без окремої сторінки й потребує підпунктів. Створення пункту меню додає посилання, а не нову сторінку сайту.

Режими видимості:

- Автоматично: інформаційні сторінки без опублікованих статей приховані; функціональні сторінки та наявні статичні статті залишаються доступними. Розділ `/own-brand` та всі наявні напрями власного виробництва, зокрема піца, є самостійними сторінками й не залежать від статей. Видимі каталоги й QR-сторінка враховуються як наповнені.
- Завжди показувати: явне ввімкнення посилання незалежно від статей.
- Приховати: прибрати пункт разом із підменю. Прямі адреси залишаються доступними.

Попередній перегляд показує незбережені зміни у вигляді головного або мобільного меню. Біля кожного пункту видно рівень, батьківський розділ, позицію та поточну видимість. Якщо БД контенту недоступна, редактор попереджає, що автоматична видимість може відрізнятися; редагування та збереження меню залишаються доступними.

Збережене меню використовується в шапці, мобільній навігації, пошуку й швидких посиланнях футера. Вони оновлюються при переході або поверненні фокусу до вкладки. Налаштування лежать у `UPLOADS_DIR/navigation/menu.json`; їх потрібно переносити разом із рештою `UPLOADS_DIR`. Записи атомарні, схему БД змінювати не потрібно. Доступ: ресурс `content`, читання для редактора, запис для збереження.

Довге підменю на комп'ютері має обмеження за висотою вікна та власну вертикальну прокрутку; мобільне меню також прокручується. Підтримуються два рівні та до 150 пунктів загалом. Для нових підпунктів можна обирати опубліковані візуальні сторінки — вони враховуються в автоматичній видимості.

Перевірки: `npm run typecheck`, `node scripts/check-site-menu.cjs`, `node scripts/check-menu-content.cjs`. Тести меню використовують окрему тимчасову папку й не змінюють робочу навігацію.


Біля кожного пункту, зокрема у згорнутій картці, є швидка кнопка «Приховати» / «Показати». Вона встановлює `hidden` / `always` відповідно до поточної видимості у попередньому перегляді. Показ прихованого через батьківський розділ підпункту заблокований із підказкою спочатку ввімкнути розділ. Індикатор та попередній перегляд змінюються одразу, публічне меню — після «Зберегти меню». Для повернення автоматичної видимості використовується наявний список «Показувати на сайті» у налаштуваннях пункту. Приховування не видаляє пункт, сторінку або її вміст.
