# Автоматичні нагадування про показники лічильників

Застосунок самостійно запускає перевірку щодня о `09:00` за київським часом. Окремий системний cron для цього не потрібен: перевірка працює в процесі `npm start` і зупиняється разом із ним.

Для кожного активного керівника магазину з Telegram chat ID, який не вніс показники за поточний місяць, застосунок надсилає повідомлення з кнопкою **«Внести показники»**. Один отримувач отримує не більш як одне таке нагадування на день; результати зберігаються в `utility_meter_reminder_logs`.

## Налаштування

Додайте до production environment:

```dotenv
# Увімкнено за замовчуванням. Встановіть 0, щоб вимкнути автоматичний запуск.
UTILITY_METER_REMINDERS_AUTO_RUN=1

# Година запуску за Europe/Kiev, від 0 до 23. За замовчуванням 9.
UTILITY_METER_REMINDERS_HOUR=9

# Рекомендований окремий секрет для захищеного endpoint.
UTILITY_METER_REMINDERS_SECRET=replace_with_a_long_random_value

# Необов'язково. Якщо не задано, використовується SITE_URL або локальна адреса застосунку.
UTILITY_METER_REMINDERS_BASE_URL=http://127.0.0.1:3000
```

Для сумісності з уже розгорнутим середовищем, де окремого `UTILITY_METER_REMINDERS_SECRET` ще немає, використовується `INVENTORY_NOTIFY_SECRET` (а потім `INVENTORY_WEBHOOK_SECRET`). Після встановлення окремого секрету він має пріоритет.

## Перевірка після деплою

У логах застосунку має з'явитися рядок:

```text
[utility-meter-reminders] auto-run enabled for 09:00 Europe/Kiev ...
```

У момент запуску успішний результат має формат `auto-run ok`, а невдалі Telegram-відправлення зберігаються в журналі зі статусом `failed`.
