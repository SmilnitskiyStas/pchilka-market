# Сторінка «Запропонувати товар»

Редактор: Admin → Контент → Співпраця: запропонувати товар (`/admin/cooperation/offer-product`). Публічна сторінка: `/cooperation/offer-product`.

Можна змінювати заголовки й вступ, додавати, видаляти та переставляти відділи й контакти, задавати посади, імена й email, замінювати ілюстрації та їхні описи, вмикати форму звернення. Зображення обираються з медіафайлів або за локальним/HTTPS-посиланням. Нові зображення завантажуються через наявний розділ «Медіафайли»; при поверненні до вкладки редактор оновлює список доступних зображень.

Прапорець «Додати до форми звернення як напрям» додає контакт до вибору категорії товару в наявній формі співпраці. Назви напрямів мають бути унікальними. Контакт безпеки початково виключений із форми. Форма використовує ті самі email та імена, що показуються на сторінці. За відсутності напрямів форма не показується.

Початкові тексти, 3 відділи й 15 контактів взято з наданих макетів. Ілюстрації з папки `img` скопійовано в `public/img/cooperation/`, шрифти Appetite й Source Sans Pro — в `public/fonts/`. Шрифти застосовані до цієї сторінки. Старий `offer_product.txt` для наповнення цієї сторінки більше не потрібний.

Налаштування зберігаються атомарно у `UPLOADS_DIR/cooperation/offer-product.json`, як і налаштування каталогів у постійному сховищі завантажень. При першому відкритті відсутній файл не створюється: використовуються початкові дані. Під час перенесення/розгортання потрібно зберігати весь `UPLOADS_DIR`; для декількох екземплярів застосунку використовуйте спільне сховище. Зміни структури БД не потрібні. Редактор і API захищені дозволами ресурсу `content`: читання для перегляду, запис для збереження.

Перевірки: `npm run typecheck`, `node scripts/check-offer-product.cjs`. Інтеграційна перевірка працює в ізольованій тимчасовій папці й перевіряє права доступу, контакти за замовчуванням, додавання/видалення/порядок, збереження, валідацію, одержувачів форми та публічний рендер.
