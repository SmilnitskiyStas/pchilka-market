# Статус проєкту Pchilka Web App

## Оновлення статусу (2026-02-23)
- Форми сайту переведено на MySQL через єдину модель `incoming_requests`.
- Додано адмін-розділ `Повідомлення` (`/admin/messages`) з фільтрами та зміною статусів.
- Для нових заявок додано вкладення файлів із серверним завантаженням і доступом через `/media/...`.
- У навігації адмінки додано лічильник необроблених заявок (`status = new`).
- Впроваджено розділення uploads по тематичних підпапках (forms/admin + feature + date).
- Важливо: нижче в документі є історичні пункти (ранні етапи з `localStorage` і старим планом), вони не є поточним джерелом істини.
