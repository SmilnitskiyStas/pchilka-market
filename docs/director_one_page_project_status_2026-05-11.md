# Коротка Інформація Для Директора

**Дата:** 11 травня 2026 року  
**Тема:** Статус реалізації двох цифрових проєктів компанії

## 1. Загальна інформація

На даний момент у роботі та на етапі погодження/тестування знаходяться два важливі проєкти:

1. **Новий вебсайт компанії**  
   Це новий сучасний вебзастосунок, який готується на заміну старому сайту та буде у вільному доступі для всіх користувачів.

2. **Система контролю партій товару**  
   Це внутрішній інструмент для обліку, контролю та перевірки товарів із взаємодією працівників через Telegram.

## 2. Поточний статус

### Новий вебсайт

- основна частина нового сайту вже реалізована;
- проєкт готовий до етапу перегляду та погодження;
- частина додаткового функціоналу буде завершуватися поетапно;
- тимчасово частина ресурсу була переведена на інший пріоритетний напрям, а саме на систему контролю товару.

### Система контролю партій товару

- базовий функціонал уже працює;
- реалізовано внесення товарів і партій;
- реалізовано контроль строків придатності;
- реалізовано сповіщення працівникам;
- реалізовано задачі для перевірки критичних товарів;
- реалізовано перший етап інвентаризації товару;
- проєкт знаходиться на стадії активного тестування.

## 3. Практична користь для компанії

### Новий вебсайт

Новий сайт дає компанії:

- сучасну та більш зручну цифрову платформу;
- оновлену публічну присутність;
- основу для подальшого розвитку онлайн-напряму.

### Система контролю товару

Система дозволяє:

- бачити товар і партії в обліку;
- контролювати строки придатності;
- призначати відповідальних працівників;
- ставити задачі на перевірку проблемного товару;
- поступово перейти до точнішого контролю фактичних залишків.

У подальшому після інтеграції з **1С** або **CashDesk** система дозволить:

- автоматично враховувати проданий товар;
- контролювати кількість товару в залишках;
- працювати за методом **FEFO**;
- своєчасно направляти працівникам задачі по критичних товарах.

## 4. Що вже зроблено

У межах цих проєктів виконано значний обсяг роботи:

- підготовлено новий вебсайт як заміну чинному;
- реалізовано внутрішню систему контролю партій товару;
- організовано роботу працівників через Telegram;
- реалізовано перевірку товару, задачі та контроль строків придатності;
- розпочато модуль інвентаризації для контролю фактичних залишків;
- підготовлено основу для наступної інтеграції з обліковими системами.

## 5. Поточний етап

Станом на сьогодні:

- **вебсайт** перебуває на стадії перегляду та погодження;
- **система контролю товару** перебуває на стадії тестування та доопрацювання.

## 6. Висновок

Обидва проєкти мають практичну цінність для компанії.

Новий сайт є важливим для зовнішнього представлення компанії, а система контролю партій товару є важливим внутрішнім інструментом для підвищення дисципліни обліку, контролю строків придатності та майбутнього точного управління залишками.
