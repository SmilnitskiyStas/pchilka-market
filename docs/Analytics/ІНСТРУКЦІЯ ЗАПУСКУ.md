# Формування звіту «Шок ціна»

Застосунок запускається локально на цьому комп’ютері з папки проєкту:

`C:\Users\loyalty\source\PchilkaWebApp`

## Варіант 1. Назви файлів містять дати

Покладіть два файли в папку `C:\Users\loyalty\source\PchilkaWebApp\docs\Analytics`, наприклад:

- `Старий з 25.08 по 31.08.26.xlsx`
- `Новий з 01.09 по 07.09.26.xlsx`

Запустіть у PowerShell:

```powershell
node scripts/build-shock-price-summary.mjs
```

## Варіант 2. Файли називаються без дат

Покладіть у папку `docs\Analytics` файли з назвами:

- `Старий.xlsx`
- `Новий.xlsx`

Запустіть:

```powershell
node scripts/build-shock-price-summary.mjs --old-from 25.08.26 --old-to 31.08.26 --new-from 01.09.26 --new-to 07.09.26
```

Дата залишку визначається автоматично як наступний день після завершення нового періоду. Для `07.09.26` це буде `08.09.26`.

Списки товарів і магазинів не записані в програмі наперед. Вони перечитуються з файлів під час кожного запуску, тому можуть змінюватися.

## Важливо про колонки джерела

У файлі `Новий.xlsx` для кожного товару повинні бути колонки:

- `Количество продажи`;
- `Остаток за вычетом текущих продаж`.

Колонка `Себестоимость (начальный остаток)` містить грошову собівартість, а не кількість товару, тому програма не використовує її як залишок. У старому звіті достатньо колонки `Количество продажи`.

Готовий файл створюється в цій самій папці. Для наведеного прикладу його назва буде:

`Шок ціна з 01.09 по 07.09.26.xlsx`

Якщо файл із такою назвою вже існує і його потрібно замінити, додайте наприкінці команди параметр `--overwrite`.

У звіт потрапляють усі рядки, назва яких починається зі слова `Магазин`. Коефіцієнти округлюються до цілих значень без десяткової частини. В інших числових колонках кінцеві нулі не показуються: наприклад, `49,000` відображається як `49`, а справжнє дробове значення `1,968` зберігається. Підсумковий рядок має назву `Разом`. Нулі зберігаються, а відсутні в одному з джерел значення залишаються порожніми та показуються як попередження після запуску.
