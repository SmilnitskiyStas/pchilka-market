# Pchilka Web App

MVP вебзастосунку магазину на Next.js + TypeScript + Tailwind.

## Швидкий старт
1. Встановити залежності: `npm install`
2. Запустити dev-сервер: `npm run dev`
3. Відкрити `http://localhost:3000`

## Структура
- `app` - сторінки застосунку
- `docs` - документація проєкту та SQL-нотатки
- `logs` - журнали виконаних робіт
- `img` - статичні зображення проєкту (логотип тощо)
