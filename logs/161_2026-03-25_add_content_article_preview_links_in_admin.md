# 161 / 2026-03-25 / add content article preview links in admin

## Що зроблено
- У модулі `Контент` додано публічне посилання на статтю під полем `slug` у формі створення та редагування.
- Для кожної статті у списку додано:
  - окреме посилання на публічну сторінку;
  - кнопку `Переглянути`.
- Додано автоматичне формування URL залежно від типу контенту:
  - `blog` -> `/blog/[slug]`
  - `news` -> `/news/[slug]`
  - `charity` -> `/about/charity/[slug]`

## Результат
- Після створення або редагування статті в адмінці одразу видно, де вона відкривається на публічному сайті.
- Адміністратору не потрібно вручну збирати URL для перевірки матеріалу.
