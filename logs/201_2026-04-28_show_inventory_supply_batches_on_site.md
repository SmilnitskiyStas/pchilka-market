# 201. Show inventory supply batches on site

Дата: 2026-04-28

## Зроблено

- Оновлено API `GET /api/inventory/manage/context`.
- API тепер повертає не лише `expiringBatches`, а й `storeBatches` - останні партії поточного магазину з розрахованим `daysLeft`.
- Оновлено сторінку `/inventory/manage`.
- Додано блок `Поточні поставки магазину`:
  - поставки згруповані за кодом партії постачання;
  - у кожній поставці видно товари, артикули, штрихкоди, кількість, дату поставки, термін придатності, дату створення;
  - для кожної партії видно відповідального користувача;
  - відповідального можна призначити або змінити одразу зі списку активних працівників магазину.
- Блок партій зі строком до 30 днів залишено окремо як операційний фокус по ризикових товарах.
- Після переназначення відповідального оновлюються обидва списки: поточні поставки і партії зі строком, що спливає.

## Перевірка

- `cmd /c npm run build` - успішно.

## Примітка

- Зміни від 2026-04-27 тепер видимі не тільки у формі внесення партії, а й у керуванні магазином: керівник бачить поставку як групу партій з товарами та відповідальними користувачами.
