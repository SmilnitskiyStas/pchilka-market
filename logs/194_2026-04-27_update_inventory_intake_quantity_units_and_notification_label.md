# 194. Update inventory intake quantity units and notification label

Дата: 2026-04-27

## Зроблено

- У формі `Нова партія товару` перейменовано поле `Кількість` на `Кількість товару`.
- Додано поруч editable поле `Одиниця вимірювання`.
- Одиниця вимірювання автоматично підтягується з вибраного товару (`products.units_of_measurement`).
- Якщо користувач змінює одиницю вимірювання під час створення партії, API оновлює її в картці товару, щоб наступного разу вона підтягувалась з бази.
- Поле `Окремі дні до сповіщення` перейменовано на `Коли повідомляти про завершення терміну придатності`.
- Додано пояснення: якщо поле порожнє, використовується стандартне значення з картки товару.

## Перевірка

- `cmd /c npm run build` - успішно.
