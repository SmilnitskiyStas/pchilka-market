# Task
Виправити ситуацію, коли після додавання кількох магазинів на публічній сторінці "Наші магазини" відображається не весь актуальний список.

# Причина
Сторінка могла віддаватися з кешу після попереднього рендеру, а API збереження магазинів не ініціювало інвалідацію кешу маршруту.

# Зміни
1. `app/api/admin/stores/route.ts`
- Додано `revalidatePath` після успішного `PUT`:
  - `revalidatePath('/about/stores')`
  - `revalidatePath('/')` (для оновлення статистики на головній, що залежить від магазинів)

2. `app/about/stores/page.tsx`
- Додано `export const dynamic = 'force-dynamic';` для примусового динамічного рендеру сторінки списку магазинів.

# Перевірка
- `npm run typecheck` — успішно.

# Результат
- Після збереження магазинів сторінка "Наші магазини" повинна показувати актуальні дані без застарілого кешу.
