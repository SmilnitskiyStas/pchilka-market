# 123 / 2026-02-18 / seo_auto_canonical_with_manual_override

## Що зроблено
- Оновлено `components/admin/admin-seo-manager.tsx`.
- Для поля Canonical додано UX:
  - за замовчуванням увімкнено `Створювати canonical автоматично`;
  - в авто-режимі поле canonical не редагується;
  - показується прев'ю сформованого canonical (наприклад, `[domain]/blog`);
  - при вимкненні авто-режиму можна внести ручні правки.
- Логіка збереження:
  - якщо авто-режим увімкнено, у правилі зберігається порожній `canonical` (runtime формує автоматично);
  - якщо авто-режим вимкнено, зберігається вручну введений canonical.
- Додано блок `Рекомендовані додаткові SEO-правила` з розширеннями:
  - Open Graph
  - Twitter Card
  - Image SEO (`alt/title/caption`)
  - JSON-LD schema
  - контроль дубльованих сторінок через robots + canonical.
