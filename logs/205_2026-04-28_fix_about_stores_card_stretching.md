# 205. Fix about stores card stretching

Дата: 2026-04-28

## Зроблено

- Виправлено верстку сторінки `/about/stores`.
- Проблема була в тому, що картки міст у зовнішньому `grid` розтягувались по висоті до найвищої картки в рядку.
- Через це міста з 1-2 магазинами отримували занадто великий порожній блок поруч із містами, де багато адрес.
- Для контейнера карток додано `items-start`.
- Для кожної картки міста додано `self-start`.

## Результат

- Короткі блоки міст тепер мають природну висоту.
- Сусідній великий блок більше не розтягує менші картки.

## Перевірка

- `cmd /c npm run build` - успішно.
