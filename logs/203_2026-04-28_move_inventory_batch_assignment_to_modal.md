# 203. Move inventory batch assignment to modal

Дата: 2026-04-28

## Зроблено

- Переглянуто `img/Screenshot_3.png`.
- У розділі `/admin/inventory -> Працівники -> Партії та відповідальні` прибрано вкладені картки з селектом всередині кожної партії.
- Основний список тепер показує компактні рядки поставок:
  - код поставки;
  - магазин;
  - кількість позицій;
  - загальну кількість товару;
  - кнопку/дію відкриття.
- При натисканні на поставку відкривається модальне вікно.
- У модальному вікні показано товари партії:
  - назва товару;
  - номер партії;
  - термін придатності;
  - кількість;
  - артикул;
  - штрихкод;
  - дата поставки;
  - користувач, який створив запис, якщо він є в `created_by_user_id`.
- Вибір користувача для партії перенесено в модальне вікно.

## Технічні деталі

- Розширено `InventoryBatchRecord` полями:
  - `createdByUserId`;
  - `createdByUserName`.
- Оновлено batch-select у `lib/inventory-batches-repository.ts`, щоб підтягувати користувача з `product_batches.created_by_user_id`.
- UI-зміни внесено в `components/admin/admin-inventory-manager.tsx`.

## Перевірка

- `cmd /c npm run build` - успішно.
