# 020_2026-02-16_tune_flipbook_like_dearflip

## Дата
2026-02-16

## Що зроблено
- Налаштовано перегляд каталогу ближче до UX `DearFlip`:
  - 1-сторінковий режим;
  - плавніше перелистування (`flip duration` ~800ms);
  - бокові стрілки для перегортання;
  - нижня панель керування з `first/prev/next/last`.
- Додано preload сусідніх сторінок для плавнішого переходу.
- Прибрано візуальні елементи, які не відповідали референсу (червоні рамки на стрілках).
- Оновлено CSS-анімацію flip для керованої тривалості через CSS variable.

## Що потрібно зробити далі
- За бажанням додати drag-перелистування (мишею/тачем), як у плагіні.
