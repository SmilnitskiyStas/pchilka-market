# Task
Зробити інтерфейс `Адмін -> Мережа -> Список магазинів` компактним і зрозумілим: групувати адреси за містами замість плоского списку карток.

# Що змінено
Файл: `components/admin/admin-network-manager.tsx`

1. Додано групування магазинів за містом (`cityGroups` через `useMemo`):
- UI тепер відображає структуру "Місто -> адреси".
- Для порожнього міста показується підпис `Без міста`.

2. Додано керування містами:
- Поле `Нове місто` + кнопка `Додати місто`.
- Редагування назви міста в хедері групи (масово для всіх адрес цього міста).
- Кнопка `Видалити місто` (видаляє всі адреси в групі).

3. Додано керування адресами в межах міста:
- Кнопка `Додати адресу` у кожній групі міста.
- Для кожної адреси залишено редагування полів: назва, адреса, телефон, години роботи, координати, активність.
- Кнопка `Видалити адресу` для окремого запису.

4. Залишено сумісність з поточною БД/API:
- Стан у компоненті й далі зберігається як плаский масив `StoreRecord[]`.
- На бекенд відправляється той самий формат (без міграцій та змін схеми БД).

# Результат
- Адмін-інтерфейс став компактніший: основний фокус тепер на містах, а адреси керуються всередині груп.
