# 204. Split inventory batch modal by users and products

Дата: 2026-04-28

## Зроблено

- Збільшено модальне вікно поставки в `/admin/inventory`.
- Модальне вікно розділено на дві частини:
  - ліворуч список користувачів магазину;
  - праворуч список товарів/партій, які додав вибраний користувач.
- Біля кожного користувача показано кількість позицій у вибраній поставці.
- Для позицій без `created_by_user_id` додано окремий пункт `Не визначено`.
- Правий список зроблено компактним:
  - назва товару;
  - номер партії;
  - код поставки;
  - статус;
  - кількість;
  - артикул;
  - штрихкод;
  - термін придатності;
  - дата поставки;
  - хто додав.
- Вибір відповідального користувача залишено в рядку товару, але у компактному вигляді.

## Перевірка

- `cmd /c npm run build` - успішно.
