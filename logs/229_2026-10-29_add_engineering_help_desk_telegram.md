# Інженерна пошта → Telegram-завдання

Додано `/admin/engineering` з окремими налаштуваннями для `engineer@legion2015.com` та `@engineering_dep_pchilka_bot`: пароль і токен вводяться на сайті та записуються до приватного `.env`, а API повертає лише ознаки їх наявності. Для production Docker додано постійний каталог налаштувань; `.env*` виключені з контексту образу.

IMAP-клієнт читає листи від `legion_admin@legion2015.com` без зміни прапорців прочитання. MIME-тема та повідомлення декодуються, tracking ID зберігається у завданні. Повторні листи з одним tracking ID оновлюють той самий запит. Message-ID/UID захищає від повторного імпорту. При першому імпорті читаються останні 7 днів. Вкладення не пересилаються.

Додано список допущених працівників, видалення/відновлення доступу, особисті сповіщення після `/start`, необов’язковий канал/групу, кнопки всіх/нових/власних завдань, прийняття, повернення та завершення. Транзакції з блокуванням рядка визначають єдиного відповідального; дії та імена зберігаються в журналі. Адміністратор може повернути активне завдання в чергу, зокрема після видалення відповідального.

Доставка має постійну чергу по адресатах і частинах повідомлення; відмова одного адресата або IMAP не зупиняє інших. Планувальник у `npm start` викликає захищений endpoint кожні 30 секунд. Шість таблиць створюються автоматично, також підготовлено SQL 043 та інструкцію `docs/engineering-help-desk.md`.

Перевірки: 6 автоматичних сценаріїв успішні (секрети та незмінність сторонніх env, MIME/tracking ID, правила прийняття/завершення й блокування рядка, відмова видаленому користувачу, повторні доставки при збої IMAP, відсутність дубля імпорту); TypeScript та production build успішні. Живе IMAP/Telegram-підключення, застосування схеми до production БД, розгортання та коміт не виконувалися. Для підключення потрібні IMAP-сервер, пароль, токен, HTTPS-адреса й Telegram ID працівників.

Локальні HTTP-перевірки production-збірки: неавторизовані GET/PUT `/api/admin/engineering` та POST `/api/engineering/webhook`, `/api/engineering/run` повертають 401; `/admin/engineering` без сесії повертає 307 на вхід. Тимчасовий сервер перевірки зупинено.
