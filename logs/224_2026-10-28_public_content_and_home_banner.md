# Публікації, службові заглушки та головний банер

Прибрано статичні демонстраційні новини, статті блогу та благодійності. Опубліковані записи БД показуються серверним компонентом PublishedPostsList в основній секції відповідного розділу, зі збереженням категорій. Окремі секції «З адмінки» більше не використовуються на цих сторінках. Чернетки й тексти сторінок виключені, є порожній стан та стан помилки БД.

Прибрано заглушки про відсутні txt-файли на rental, search-room, offer-equipment, marketing-services. Карусель перейшла на адаптивні Next Image з пріоритетом першого слайда; запити банерів та статистики головної паралельні. Проксі читає локальні шляхи з URL-encoding.

Перевірки: check-public-publications.cjs (публікації / чернетки / призначення / порожній список / помилка), check-banner-playback.cjs (оптимізовані зображення, відео та діапазони), TypeScript, npm run build. Документація: docs/public-publications.md. Віддалена БД та розгортання не змінені.

Результат: повна збірка завершилася успішно (191 сторінка). У локальному production-процесі перевірено запит оптимізатора головного банера через site-image: HTTP 200, image/webp, 81 448 байтів для зображення production.png при w=640, q=75. Процес зупинено після перевірки.
