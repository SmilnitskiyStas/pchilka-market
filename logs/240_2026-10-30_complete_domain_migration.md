# Перенесення нового сайту на основний домен

Новий сайт переключено з `pchilka-new.eatshock.com` на `pchilka-market.ua` на поточному сервері. DNS не змінювався. nginx основного домену направлено на чинний Next.js контейнер, www і старі публічні сторінки отримали 308. Старі API та ресурси залишені прямими для сумісності. WordPress і його БД збережені; старі uploads проксуються через його static backend. Прямий nginx alias повертав 403 через права директорій, після виправлення перевірений JPG повертає 200.

Оновлено серверне й локальне оточення адреси сайту, три активні Telegram-налаштування та їх webhook, локальну адресу синхронізації лояльності, fallback POS runner і приклади касових скриптів. Локальний POS-ключ синхронізовано з серверним без зміни серверного ключа. Секрети не виводилися та не додавалися до Git.

Внутрішні runner використовують loopback: серверні звернення до власної публічної адреси не проходили. Початкове переключення контейнера виконано з тим самим образом.

Перевірено: здоров'я БД, головна й ресурси, sitemap/robots/QR, авторизація адміністратора, три webhook без помилок і черг, редиректи зі шляхами/query, прямі захищені API старого й нового доменів, авторизація локальних loyalty/POS-клієнтів без запису даних. Контейнер healthy. `node --check run-pos-archive.cjs` і `git diff --check` успішні.

Докладний стан, обмеження перевірок, серверні шляхи, копії та відкат: `docs/domain-migration.md`. Масові відправлення й повне передавання транзакцій не запускалися. Інженерний бот до перенесення не мав збережених налаштувань у робочому контейнері, його webhook не змінювався.
