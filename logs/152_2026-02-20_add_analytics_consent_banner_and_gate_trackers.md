# 152 — Consent-банер для аналітики та блокування трекерів без згоди

## Що зроблено
- Додано модель згоди на клієнті:
  - `lib/analytics-consent.ts`
  - Зберігання в `localStorage` (`analytics_consent_v1`)
  - Подія зміни стану (`analytics-consent-changed`)
- Додано UI-банер згоди:
  - `components/analytics-consent-banner.tsx`
  - Варіанти: `Прийняти` / `Відхилити`
  - До вибору банер показується; після вибору ховається.
- Перероблено завантаження аналітики:
  - `components/analytics-loader.tsx`
  - GA4/GTM/Meta Pixel підключаються тільки якщо consent = `accepted`.
  - При `rejected` або `unset` трекінг-скрипти видаляються/не завантажуються.
  - Компонент реагує на зміну consent в поточній вкладці і між вкладками.
- Додано додатковий запобіжник подій:
  - `lib/analytics-events.ts`
  - `trackAnalyticsEvent()` ігнорує відправку без consent.
- Підключено банер глобально:
  - `app/layout.tsx`.

## Перевірка
- `npm run typecheck` — успішно.

## Що залишилось
- За потреби додати посилання на політику конфіденційності в текст банера.
- За потреби додати кнопку "Змінити згоду" в футер або налаштування.
