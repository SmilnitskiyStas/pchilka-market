# 160 / 2026-03-25 / add promotion preview links in admin

## Що зроблено
- В адмін-панелі акцій додано явне посилання на публічну сторінку акції під полем `slug`.
- У списку акцій для кожного запису додано:
  - окремий URL `/promotions/[slug]`;
  - кнопку `Переглянути`, що відкриває сторінку в новій вкладці.
- Реалізовано динамічну сторінку `app/promotions/[slug]/page.tsx`, яка читає акцію з БД за `slug` і показує її як окрему публічну сторінку.
- Для сторінки акції додано базові metadata:
  - `title`;
  - `description`;
  - `canonical`;
  - `robots` (`noindex,nofollow` для не опублікованих акцій).

## Результат
- Після створення або редагування акції в адмінці одразу видно, за яким посиланням її можна відкрити.
- Адмін більше не залежить від вручну створених статичних сторінок для кожної нової акції.

## Примітки
- Статуси `draft` і `archived` також можна відкрити за прямим URL для прев’ю з адмінки, але вони позначаються як неіндексовані через `robots`.
