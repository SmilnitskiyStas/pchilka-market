# 193. Unify inventory intake date fields

Дата: 2026-04-27

## Зроблено

- У формі `Нова партія товару` замінено два окремі поля для дат на один видимий input з кнопкою календаря.
- Для `Термін придатності` і `Дата поставки` тепер можна вручну ввести дату у форматі `дд.мм.рррр` або відкрити календар через іконку.
- Вибір з календаря записується у те саме поле у звичному локальному форматі.

## Перевірка

- `cmd /c npm run build` - успішно.
