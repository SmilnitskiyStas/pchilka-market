# 012_2026-02-16_disable_pdf_scroll_in_catalog_view

## Дата
2026-02-16

## Що зроблено
- Для сторінки `/promotions/catalog` вимкнено взаємодію з вбудованими PDF iframe:
  - додано `pointer-events-none` для iframe;
  - прибрано можливість скролу/кліку всередині PDF.
- Навігація по каталогу залишається тільки через кнопки `Попередні` / `Наступні`.

## Що потрібно зробити далі
- За потреби додати окремий режим "Інтерактивний перегляд", який можна вмикати/вимикати перемикачем.
