# 197. Highlight inventory barcode lookup status

Дата: 2026-04-27

## Зроблено

- У формі `Нова партія товару` додано локальний візуальний статус для поля `Пошук товару або штрихкод`.
- Якщо товар знайдено за штрихкодом, поле стає зеленим і під ним показується назва знайденого товару.
- Якщо сканований штрихкод не знайдено, поле стає червоним і під ним показується повідомлення про відсутність товару в базі.
- При ручному редагуванні не-barcode значення статус очищається, щоб звичайний пошук за назвою не підсвічувався помилково.

## Перевірка

- `cmd /c npm run build` - успішно.
