# Згорнуті картки піц і вибір магазинів

У `/admin/own-brand` збережені картки піц тепер спочатку закриті. Назва відкриває поля, нова картка відкривається одразу; є «Згорнути всі піци». Правки зберігаються у стані при згортанні, картки без назви відкриваються при валідації. Каталог зображень і редагування наявних полів збережені.

Додано блок «Магазини з піцою» з пошуком, прапорцями, вибором знайдених, очищенням і окремим збереженням. Він використовує лише активні записи stores із містом та адресою. Новий API `GET/PUT /api/admin/own-brand/pizza-stores` перевіряє права own_brand та всі ID до запису. Збереження атомарне в `UPLOADS_DIR/own-brand/pizza-stores.json`.

Публічна сторінка групує обрані актуальні адреси за містом; неактивні чи видалені магазини приховані. Явний порожній вибір не повертає старі адреси. До першого збереження підтримується текстове джерело, якщо файл існує; в адмінці позначаються точні збіги, незіставлені адреси потребують перевірки користувача. Робочий вибір не змінювався тестовими запитами.

Розгорнуто `pchilka-pizza-editor:20261030` (`aac46acc78ee`), healthy. На сервері збережені 19 піц побайтово, новий захищений API повернув 36 доступних магазинів. Чинний runtime .env інженерної служби також перенесено без зміни вмісту у вже передбачене репозиторієм постійне сховище, щоб не втратити налаштування під час перезапуску. Усі секрети залишилися приватними. Схему й дані stores не змінювали.
