# YouTube iframe у редакторі матеріалів

Дата: 2026-10-30.

Додано кнопку YouTube в admin/content, поле URL/iframe-коду та вставлення у запам’ятовану позицію курсора. Валідація пояснює помилку без зміни тексту; при зміні матеріалу або скиданні редактора панель очищується. Прийнятий iframe нормалізується в канонічний URL без сторонніх атрибутів.

ArticleBody розпізнає звичайні й Markdown YouTube-посилання окремим рядком, одно- й багаторядкові iframe. Вихідний HTML не виконується: для відео створюється власний iframe за дозволеним HTTPS-доменом та ID; інші iframe залишаються екранованим текстом. Зберігаються текст до/після та декілька відео. Публічні динамічні новини/благодійність переведено на спільний ArticleBody, який вже використовують блог і матеріали сторінок.

Перевірки: scripts/check-page-content-rendering.cjs (реальний редактор із тестовими React hooks: помилка, вставлення, збереження попереднього тексту; рендер URL, Markdown, iframe з атрибутами та багаторядкового iframe; декілька відео; відмова для зовнішнього домену, javascript, srcdoc без src і повторного src), scripts/check-visual-pages.cjs (регресія конструктора), TypeScript без incremental, git diff --check. Робочу БД і Telegram не використовували.

Оновлено docs/site_content.md. Схема контенту та наявні дані не змінювалися. Серверна збірка та розгортання не виконувалися. Сторонні .gitignore і tsconfig.tsbuildinfo не включаються.
