# 154 — Повне керування картками «Шок ціна» з адмінки

## Що зроблено
- Додано окремий storage для керованих карток «Шок ціна» в `site_settings`:
  - `lib/shock-price-gallery.ts`
  - `lib/shock-price-gallery-repository.ts`
  - ключ: `shock_price_gallery_v1`
- Додано API для карток:
  - `app/api/admin/shock-price/gallery/route.ts`
  - `GET` — отримати картки
  - `PUT` — зберегти картки (захищено admin-сесією)
- Додано повноцінний UI в адмінці:
  - `components/admin/admin-shock-price-manager.tsx`
  - Підключено в `components/admin/admin-promotions-manager.tsx`
  - Можливості:
    - додати картку по URL/шляху;
    - вибрати зображення з серверної бібліотеки (`/api/admin/images`);
    - завантажити новий файл і одразу використати;
    - змінити назву, URL, активність;
    - ручний порядок (кнопки вгору/вниз);
    - видалення карток;
    - збереження всього набору в БД.
- Оновлено публічну сторінку:
  - `app/promotions/shock-price/page.tsx`
  - Пріоритет:
    1) якщо є керовані картки з БД — використовуються вони в заданому порядку;
    2) якщо карток у БД немає — fallback на сканування `public/img/shock_price`.
- Підтверджено коректність збірки типів:
  - `npm run typecheck` — успішно.

## Поведінка після релізу
- Ви можете керувати тим, яке зображення за яким іде, без перейменування файлів.
- Налаштування сітки (колонки/ліміт/sort fallback) залишаються доступними в секції «Шок ціна».
