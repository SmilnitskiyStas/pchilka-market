# 130 / 2026-02-18 / extend_admin_content_articles_with_categories_editor_and_image_picker

## Що зроблено
- Розширено блок `Статті` в `components/admin/admin-content-manager.tsx`.

### 1) Категорії при створенні статті
- Додано вибір категорій через чекбокси.
- Категорії фільтруються за обраним блоком контенту (`blog`/`news`/`charity`).
- Збереження статті включає `categoryIds`.

### 2) Розширений текстовий редактор
- Додано поле `body` (основний контент статті).
- Додано toolbar для вставки форматування markdown:
  - H2, H3
  - жирний, курсив
  - маркований і нумерований список
  - посилання
  - вставка зображення
- Кнопки вставляють формат у позицію курсора.

### 3) Cover image: вибір із сервера
- Додано API `app/api/admin/images/route.ts`:
  - сканує `public/img` рекурсивно
  - повертає список шляхів `/img/...`
- У формі статті додано модальне вікно `Обрати з сервера`:
  - пошук по шляху
  - мініатюри та вибір зображення для `coverImage`.

### 4) Cover image: завантаження файлу
- Додано кнопку `Завантажити файл`.
- Локальний файл читається як data URL і підставляється у `coverImage` (MVP локальне збереження).

### 5) Оновлено модель контенту
- `lib/content-entries.ts`:
  - додано поля `body`, `categoryIds`
  - оновлено нормалізацію/збереження.

## Перевірка
- Виконано `npm.cmd run typecheck`.
- Результат: без помилок.

## Що залишилось
- Для production перенести завантаження файлів з data URL у реальне сховище (Supabase Storage).
- Підключити рендер `body` (markdown/html) на публічних сторінках, коли перейдемо зі статичних `content/*.ts` на дані адмінки.
