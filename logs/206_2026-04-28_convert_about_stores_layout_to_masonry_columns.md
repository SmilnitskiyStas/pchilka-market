# 206. Convert about stores layout to masonry columns

Дата: 2026-04-28

## Зроблено

- Перероблено розкладку карток міст на сторінці `/about/stores`.
- Замість звичайного `grid` із двома колонками застосовано колоночну masonry-подібну схему:
  - контейнер: `columns-1 md:columns-2`;
  - картка міста: `break-inside-avoid` + `mb-4`.

## Результат

- Короткі картки міст більше не залишають порожню область під собою.
- Наступні картки піднімаються у вільний простір в колонці.
- Сторінка виглядає щільніше і природніше при різній кількості адрес у містах.

## Перевірка

- `cmd /c npm run build` - успішно.
