# Виправлення типу props сторінки оренди

Production-збірка Next.js відхиляла перший аргумент RentalPage як `RentalPageProps | undefined`: значення параметра за замовчуванням `= {}` робило аргумент необов’язковим. При попередній перевірці звичайного TypeScript ця помилка не виявилась, бо повна збірка генерує додаткові перевірки контрактів App Router.

Видалено значення параметра за замовчуванням у сторінці та generateMetadata, обидва використовують спільний тип RentalPageProps. Асинхронний searchParams збережений. Інтеграційний тест передає об’єкт props, як це робить Next.js.

Перевірки `node scripts/check-menu-content.cjs` та повна `npm run build` пройшли. Next.js успішно перевірив типи, згенерував 203 статичні сторінки та завершив оптимізацію і build traces з кодом 0. Перевірено локальну production-збірку; Docker-образ окремо не збирався. Коміт і розгортання не виконувалися.
