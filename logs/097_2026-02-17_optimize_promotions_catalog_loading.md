# 097_2026-02-17_optimize_promotions_catalog_loading

## Дата
2026-02-17

## Проблема
- Сторінка `/promotions/catalog` могла завантажуватись дуже довго (до хвилини), бо клієнт одразу рендерив усі сторінки PDF у зображення для flipbook.

## Що змінено
- У `components/promotion-catalog-viewer.tsx` змінено стратегію рендеру:
  - режим за замовчуванням: швидкий `iframe` (PDF);
  - `Книжковий режим` (flipbook) тепер вмикається вручну кнопкою;
  - для великих каталогів книжковий режим обмежено (до 16 сторінок), щоб уникнути довгого прелоаду;
  - додано інформаційний текст про автоматичний швидкий режим для великих файлів;
  - додано кнопку повернення з flipbook у PDF-режим.

## Результат
- Каталог відкривається значно швидше, без блокуючого рендеру всіх сторінок перед першим показом.

## Перевірка
- `npm run typecheck` — успішно.
