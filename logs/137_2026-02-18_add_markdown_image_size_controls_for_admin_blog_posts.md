# 137 / 2026-02-18 / add_markdown_image_size_controls_for_admin_blog_posts

## Що зроблено
- Додано керування розміром зображень у markdown для статей з адмінки.

### Рендер статті
- Оновлено `components/admin-blog-post-page.tsx`:
  - підтримка синтаксису image meta в alt-частині:
    - `![alt|w=640](url)`
    - `![alt|w=640|h=360](url)`
  - парсер виділяє `w` та `h` і застосовує їх до стилю `<img>`.
  - якщо розмір не задано, використовується ширина `100%` і auto-висота.

### Редактор статті
- Оновлено `components/admin/admin-content-manager.tsx`:
  - кнопка `Зображ.` тепер вставляє шаблон `![alt|w=640]()`.
  - у блоці пояснення markdown додано приклад з розміром:
    - `![alt|w=640|h=360](/img/path.jpg)`.
