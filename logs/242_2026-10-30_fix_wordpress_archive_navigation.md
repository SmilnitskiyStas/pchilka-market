# Доступ до архівного WordPress без переходу на новий сайт

За адресою `http://5.189.190.36:3002/` старий WordPress використовував production WP_HOME/WP_SITEURL. CSS/JS формувалися на основному домені, а перехід на `/picza/` міг редиректити на IP без порту.

WP_HOME і WP_SITEURL у серверному wp-config.php змінено на повну архівну адресу з портом 3002. Попередній config збережено у приватному `/srv/pchilka-app/backups/wordpress-archive-20261030-090512`.

Жорстко записані адреси меню та контенту переписуються лише у frontend-відповіді за архівного Host через MU-плагін `pchilka-archive-links.php`. Копію плагіна додано до `deploy/wordpress/`. БД, контент і медіафайли не змінювалися. Основний домен не проходить через це переписування.

Перевірено: PHP syntax, головна й `/picza/` — 200 без зміни адреси; 41 локальний CSS/JS — 200; у навігації та ресурсах цих сторінок немає посилань на основний домен; новий Next.js health API — 200. Для обходу раніше закешованого 301 можна використати `/picza/?archive=1`.
