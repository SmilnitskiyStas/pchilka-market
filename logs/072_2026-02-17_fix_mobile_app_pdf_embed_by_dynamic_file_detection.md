# 072_2026-02-17_fix_mobile_app_pdf_embed_by_dynamic_file_detection

## Дата
2026-02-17

## Що зроблено
- Виправлено відображення PDF на сторінці `Програма лояльності -> Мобільний застосунок`.
- Причина: hardcoded назва файлу не співпадала з реальною назвою PDF (спецсимволи/лапки у файлі), через що URL був некоректний.
- Реалізовано динамічне визначення PDF-файлу з папки `public/img/loyalty_programm` на сервері.
- Вбудований перегляд (`iframe`) та кнопка `Відкрити PDF` тепер використовують фактично знайдений файл.
- Додано fallback, якщо PDF у папці відсутній.
