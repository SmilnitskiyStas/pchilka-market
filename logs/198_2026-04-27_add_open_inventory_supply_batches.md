# 198. Add open inventory supply batches

Дата: 2026-04-27

## Зроблено

- Додано список відкритих партій поставки за поточний день для магазину користувача.
- У формі `Нова партія товару` поле `Партія постачання` тепер:
  - показує відкриті партії сьогодні;
  - дозволяє вибрати існуючу партію одним кліком;
  - дозволяє залишити поле порожнім, щоб сервер автоматично відкрив нову партію.
- Після збереження першого товару нової партії форма залишає цей код партії в полі, щоб наступні товари потрапляли в ту саму поставку.
- Якщо партію не вказано, сервер генерує код виду `STORE-YYYYMMDD-XX`.
- Генерація нового коду захищена MySQL `GET_LOCK`, щоб паралельні користувачі не отримували один і той самий номер нової партії.

## Технічні деталі

- Нові функції в `lib/inventory-batches-repository.ts`:
  - `listOpenInventoryBatchCodesForStoreInDb`;
  - `generateNextInventoryBatchCodeForStoreInDb`.
- `app/api/inventory/intake/context/route.ts` повертає `openBatchCodes` і `nextBatchCode`.
- `createInventoryBatchInDb` автоматично генерує `batch_code`, якщо він не переданий.

## Перевірка

- `cmd /c npm run build` - успішно.

## Залишилось

- Якщо надалі потрібне явне закриття партій, варто додати окрему таблицю поставок або статус партії. Поточна MVP-логіка вважає відкритими партії поточного дня.
