# Швидке приховування пунктів меню

Дата: 2026-10-30.

У admin/menu режим «Приховати» вже підтримували API та публічна фільтрація, але поле було всередині згорнутих налаштувань. Додано видимі кнопки «Приховати» / «Показати» в заголовках карток головного меню та підпунктів. Кнопки змінюють наявне поле visibility на hidden / always; автоматичний режим залишається у детальних налаштуваннях. Для підпункту прихованого розділу кнопка показу недоступна, підказка пояснює причину. Публічні дані змінюються лише після явного збереження меню. Додано пояснення про підменю й доступність прямих адрес.

Перевірки: TypeScript без incremental та scripts/check-site-menu.cjs. Схема зберігання й API не змінювалися; тест меню перевіряє приховані пункти та авторизоване збереження в тимчасовому сховищі. Серверна збірка й розгортання не запускалися. Сторонні зміни .gitignore і tsconfig.tsbuildinfo не включаються.
