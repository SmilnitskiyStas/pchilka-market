# Заміна ілюстрації лояльності на кероване зображення

Дата: 2026-10-30.

На головній замінено складену HTML/CSS-ілюстрацію мобільного застосунку на фото 2 з повідомлення користувача. Файл скопійовано без зміни байтів у public/img/loyalty/mobile-app-home.png; SHA256 оригіналу та копії збігаються: da03cfb8d7c8e27232cca855574178e45899d360acd6a71bb646e39143adadbf. PNG 1440×600 із прозорістю; збережено пропорції та повне зображення. Next Image unoptimized не перекодовує QR-код. Заголовок, опис і переходи лояльності збережено.

У admin/home-slides додано окремий блок керування: завантаження файлу або URL, опис, preview, явне збереження та повернення оригіналу. Під час помилки початкового читання збереження заблоковано, доступна повторна спроба. API використовує наявний ресурс banners, upload — media. Налаштування зберігаються атомарно в UPLOADS_DIR/home/loyalty-image.json. За відсутності налаштувань відразу використовується надане фото 2; на головній безпечний fallback при помилці читання.

Перевірки: TypeScript без incremental; scripts/check-home-loyalty-image.cjs (тимчасове сховище, реальні API/сесії, права, валідація, запис/читання, черга атомарних збережень, реальний SSR головної з вибраним зображенням та fallback, PNG/alpha); git diff --check; порівняння SHA256. Тест не звертається до робочої БД або мережі.

Оновлено docs/site_content.md і docs/uploads_storage.md. Серверна збірка, розгортання й зміни робочих даних не виконувалися. Сторонні .gitignore і tsconfig.tsbuildinfo не включаються.
