# Етап 3: розширення бібліотеки блоків

Додано перетягування блоків у списку з альтернативними кнопками зміни порядку для клавіатури та телефона. Додано форматування текстових блоків кнопками (жирний, курсив, список, посилання) зі спільним безпечним відображенням на полотні та публічній сторінці. Форматування зберігається текстовими маркерами; довільний HTML не виконується.

Нові блоки: дві текстові колонки, банер із необов’язковим зображенням і кнопкою, відеофайл MP4/WebM та готова форма оренди. Колонки переходять в один стовпець на вузькому контейнері. Форма використовує наявний компонент надсилання заявок; у перегляді редактора та чернетки показується пояснювальний блок без надсилання. Дозволена одна форма на новій сторінці; для rental-intro додавання заборонене, оскільки сторінка вже має власну форму.

Зображення, банери та відео мають вбудований вибір із медіабібліотеки, пошук і завантаження через наявний API images. Зберігаються існуючі права на медіазавантаження. Під час асинхронного завантаження редагування та збереження сторінки блокуються, щоб не втратити зміни; помилки показуються біля поля. Імена файлів із пробілами й кирилицею кодуються для коректних URL.

Перевірки: TypeScript; scripts/check-visual-pages.cjs (нові типи, SQL/API round trip, перестановка без мутації, серверне відображення, безпечні URL, заборона дублювання форми); scripts/check-menu-content.cjs та scripts/check-site-menu.cjs. У браузері з БД у пам’яті перевірено форматування виділеного слова, drag-and-drop, зміну порядку Enter-клавішею, вибір зображення з медіабібліотеки, додавання форми та її заглушку, збереження чернетки й перехід колонок у вертикальне розміщення для телефона. Знімок: outputs/visual-editor-stage-three.jpg. Завантаження реальних файлів, відтворення відео й робоча БД не перевірялися. Коміт і розгортання не виконувалися.
